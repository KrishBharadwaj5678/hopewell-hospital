## <img src="https://github.com/KrishBharadwaj5678/hopewell-hospital/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/hopewell-hospital.git
````

### 2️⃣ Aceder ao Diretório do Projeto

```bash
cd hopewell-hospital
```

### 3️⃣ Instalar as Dependências

```bash
npm install
```

### 4️⃣ Iniciar o Servidor de Desenvolvimento

```bash
npm run dev
```
