## <img src="https://github.com/KrishBharadwaj5678/hopewell-hospital/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/hopewell-hospital.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd hopewell-hospital
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ 開発サーバーを起動

```bash
npm run dev
```
