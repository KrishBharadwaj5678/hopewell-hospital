## <img src="https://github.com/KrishBharadwaj5678/hopewell-hospital/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/hopewell-hospital.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd hopewell-hospital
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Запуск сервера разработки

```bash
npm run dev
```
